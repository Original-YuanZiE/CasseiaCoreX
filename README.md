# CasseiaCoreX 工具箱

一个基于 WinUI3 的系统工具箱

![应用截图](https://github.com/Original-YuanZiE/CasseiaCoreX/raw/master/ScreenShot.png)

环境要求：

.NET 8.0

Windows App SDK 2.5.1

64 位系统

最低 Windows 版本 10.0.17763.0

系统已安装 Segoe Fluent Icons 字体

部分功能需要管理员权限


功能列表：

## 主页

1. 查看配置信息

## 系统设置

1. 隐藏快捷方式小箭头
2. 解锁 Windows 11 平板任务栏
3. 任务栏时钟显秒
4. 设置命令提示符启动时自动执行的命令
5. 启用长路径支持
6. 启用 LogonUI 详细信息
7. 调整用户账户控制（UAC）设置
8. 禁用 Defender 实时保护
9. 禁用 Windows 更新
10. 设置最大暂停更新天数（仅对 Windows 11 25H2 以下版本及 25H2 部分版本生效）
11. 无 GPU 驱动时强制启用 Mica 与圆角效果
12. 设置 OEM 信息
13. 清除已安装密钥
14. [暂时失效] 数字激活 Windows（HWID）
15. 家庭版转专业版
16. 备份激活密钥
17. 集成 Microsoft Activation Scripts (MAS)

## 常用工具

1. 备份驱动
2. 导入驱动（仅支持 *.inf 驱动）
3. 补全 Windows Media Foundation Codecs
4. 图片与媒体格式转换（支持常用格式与 NCM 解密）

## Android 调试

1. ADB 调试
2. 安装应用
3. 获取截屏
4. 管理应用
5. ADB 控制台等功能
