# CasseiaCoreX 工具箱

一个基于 WinUI3 的系统工具箱

![应用截图]("https://github.com/Original-YuanZiE/CasseiaCoreX/blob/master/ScreenShot.png?raw=true")

环境要求：

.NET 8.0

Windows App SDK 2.2.0

64 位系统

最低 Windows 版本 10.0.17763.0

系统已安装 Segoe Fluent Icons 字体

大部分功能需要管理员权限



功能列表：

1. 查看配置信息
2. 隐藏快捷方式小箭头
3. 解锁 Windows 11 平板任务栏
4. 任务栏时钟显秒
5. 设置命令提示符启动时自动执行的命令
6. 启用长路径支持
7. 启用 LogonUI 详细信息
8. 调整用户账户控制（UAC）设置
9. 禁用 Defender 实时保护
10. 禁用 Windows 更新
11. 设置最大暂停更新天数（仅对 Windows 11 25H2 以下版本及 25H2 部分版本生效）
12. 清除已安装密钥
13. [暂时失效]数字激活 Windows （HWID）
14. 家庭版转专业版
15. 备份激活密钥
16. 备份驱动
17. 导入驱动（仅支持 \*.inf 驱动）
18. 无 GPU 驱动时强制启用 Mica 与圆角效果
19. 设置 OEM 信息
20. ADB 调试（安装应用、获取截屏、管理应用等）
21. 集成 Microsoft Activation Scripts (MAS)

本软件参考/使用了以下开源项目：

[Microsoft Activation Scripts (MAS)](https://github.com/cmontage/mas-cn/tree/main)
